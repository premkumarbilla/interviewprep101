How to work each problem

Time-box it

Give an Easy 15 minutes and a Medium 25–30. If you're stuck, open the hint. If you're still stuck, read a solution, then close it and write it yourself.

Say the pattern first

Before coding, name the pattern and the complexity you're aiming for. That habit is what transfers to new problems in the assessment.

Test edge cases yourself

Empty input, one element, duplicates, negatives, and the largest size the problem allows. Assessments often grade on hidden tests like these.

Redo what you missed

Any problem you needed the solution for, solve again from scratch the next morning before starting that day's set.
